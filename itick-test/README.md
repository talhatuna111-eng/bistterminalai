# iTick BIST Live Test

Authorized iTick free-trial adapter for Borsa Istanbul.

## Official endpoints
- REST: https://api-free.itick.org/stock
- WebSocket: wss://api-free.itick.org/stock

## Environment
- ITICK_API_KEY (secret)
- SYMBOLS (default THYAO,GARAN,ASELS)
- ITICK_REGION (default TR)
- ITICK_TYPES (default quote,tick)
- ITICK_WS_URL
- ITICK_REST_BASE

No API key is stored in GitHub.
